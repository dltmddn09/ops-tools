# 코드 발급 품의서 체크 작업 규칙

그룹웨어 「게임 코드 발급 요청서」 품의서를 붙여넣으면 플랫폼·권역·상품별 발급 수량을 뽑고, 관리대장(엑셀) 빈 줄에 한 번에 붙일 수 있는 줄을 복사해 주는 정적 페이지다. 외부 라이브러리 없음. 붙여넣은 품의서는 브라우저 안에서만 처리하며 서버로 보내지 않는다.

## 동작 규칙 (바꿀 때 사용자 확인)

- **입력**: 서식 포함 복사(HTML, 표 구조·체크박스 상태 유지)를 우선 읽고, 글자만 붙여넣으면 탭 구분 텍스트로 읽는다. 글자만일 때는 체크박스(요청 경로·제공 대상)를 못 읽으므로 화면에서 직접 고르게 한다.
- **다국어**: 한국어·영어·일본어·중문 번체 양식을 읽는다. 언어별 표기는 스크립트 상단 `LABEL`·`ROUTE_ALIAS`·`TARGET_ALIAS`·`GROUPS`·`OTHER`·`*_PLACEHOLDERS`·`REGION_ALIAS`·`PHASE`에 모여 있다. 새 언어는 양식 소스를 받아 각 목록 끝에 추가한다. 관리대장에 들어가는 요청 경로·제공 대상은 한국어 표기로 통일한다.
- **배포 소속·담당자**: 「소속:」「담당자명:」 머리말이 있으면 머리말로, 작성자가 지우고 값만 썼으면 칸 순서(첫 칸 소속·둘째 칸 담당자)로 읽는다.
- **복사 열 순서**: `품의번호 | 플랫폼·권역 | 상품 | 발급자 | 요청 수량 | 상태(미발급) | 요청 경로 | 제공 대상 | 게임 타이틀 | 배포 소속 | 배포 담당자 | 발급 희망일·유효기간` — 관리대장 A~L 열과 같아야 한다. 줄바꿈은 `\n`(`\r\n`이면 엑셀에 빈 줄이 끼어들 수 있다).
- **「기타」 요청**은 줄을 만들지 않고 확인 사항으로만 알린다.
- **발급자**는 브라우저 localStorage에 기억한다.

## 테스트

- 테스트용 품의서는 이 폴더에 두지 않는다. 레포가 공개라 실제 품의서 내용(요청 사유·배포 담당자 등)이 노출된다.
- 4개 언어 × (서식 복사 / 글자만) 로 같은 수량이 나오는지, 빈 양식에서 안내 문구가 값으로 들어가지 않는지 확인한다.
