# notice-search (CD 공지 검색)

붉은사막 공식 홈페이지 새소식(업데이트·공지사항) 전문 검색 페이지. 팀 공유 URL: https://dltmddn09.github.io/ops-tools/notice-search/

- 언어: 공홈 언어 선택 메뉴의 14개 전부(ko-KR, en-US, zh-CN, zh-TW, ja-JP, de-DE, fr-FR, es-ES, es-MX, it-IT, pl-PL, pt-BR, ru-RU, tr-TR, 2026-10-10부터). 상단 드롭다운, 주소 `#lang=de-DE`(예전 `#lang=en`·`#lang=zh`도 호환), 브라우저 localStorage로 언어를 고른다. 드롭다운의 언어 이름은 공홈 메뉴 표기 그대로다.
- 화면 문구는 `index.html`의 `T` 객체에 한국어·영어·간체만 있고(영어·간체는 공식 번역이 아니라 이 페이지용으로 쓴 것), 나머지 11개 언어는 영어 문구를 쓴다. 업데이트·공지사항 탭 이름은 수집기가 공홈의 언어별 탭 표기를 함께 저장한 것을 쓴다(한·영·간체는 `T` 우선). 게시 시간은 모든 언어 KST로 표시한다.
- `index.html`: 검색 UI. 고른 언어의 `data/{언어}.js`만 그때 불러온다. 검색 조건은 "띄어 쓴 단어가 같은 줄에 모두 포함"만 있다. 고도화는 사용자 요청이 있을 때만 한다.
- `data/{언어}.js`: **직접 수정하지 말 것.** `claude-work`의 `패치노트 아카이브/수집.py`가 생성한다.
- 갱신: 작업 스케줄러 `CD 공지 검색 갱신`(매주 월요일 10:30)이 `패치노트 아카이브/주간 갱신.ps1`을 실행한다. 수집 → `data/`가 바뀌었으면 이 레포 커밋·푸시 → 상위 `claude-work` 서브모듈 포인터 커밋·푸시 순서다.
- 수동 갱신: `패치노트 아카이브\지금 갱신.bat` 더블클릭. 주간 잡과 같은 스크립트를 실행하고, 끝나면 결과 로그를 보여준다(약 4분. 14개 언어를 4개씩 병렬 수집, 언어당 약 1분).
- 게시판 목록에 공개된 글만 수집한다. 목록에서 내려간 글도 주소를 직접 치면 열리지만 수집 대상이 아니다.
- 페이지 상단의 수집 주기 문구(`매주 월요일 10:30 자동 수집`)는 스케줄을 바꾸면 같이 고친다.
