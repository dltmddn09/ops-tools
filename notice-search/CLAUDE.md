# notice-search (CD 공지 검색)

붉은사막 공식 홈페이지 새소식(업데이트·공지사항) 전문 검색 페이지. 팀 공유 URL: https://dltmddn09.github.io/ops-tools/notice-search/

- 언어: 한국어(ko-KR)·영어(en-US)·중국어 간체(zh-CN). 상단 전환 버튼, 주소 `#lang=en`·`#lang=zh`, 브라우저 localStorage로 언어를 고른다. 공홈에는 다른 언어도 있으나 사용자가 이 셋만 요청했다. 화면 문구의 영어·중문은 공식 번역이 아니라 이 페이지용으로 쓴 것이다. 화면 문구는 `index.html`의 `T` 객체에 언어별로 모여 있다. 게시 시간은 두 언어 모두 KST로 표시한다.
- `index.html`: 검색 UI. `data.js`를 읽는다. 검색 조건은 "띄어 쓴 단어가 같은 줄에 모두 포함"만 있다. 고도화는 사용자 요청이 있을 때만 한다.
- `data.js`: **직접 수정하지 말 것.** `claude-work`의 `패치노트 아카이브/수집.py`가 생성한다.
- 갱신: 작업 스케줄러 `CD 공지 검색 갱신`(매주 월요일 10:30)이 `패치노트 아카이브/주간 갱신.ps1`을 실행한다. 수집 → `data.js`가 바뀌었으면 이 레포 커밋·푸시 → 상위 `claude-work` 서브모듈 포인터 커밋·푸시 순서다.
- 수동 갱신: `패치노트 아카이브\지금 갱신.bat` 더블클릭. 주간 잡과 같은 스크립트를 실행하고, 끝나면 결과 로그를 보여준다(약 6분).
- 게시판 목록에 공개된 글만 수집한다. 목록에서 내려간 글도 주소를 직접 치면 열리지만 수집 대상이 아니다.
- 페이지 상단의 수집 주기 문구(`매주 월요일 10:30 자동 수집`)는 스케줄을 바꾸면 같이 고친다.
